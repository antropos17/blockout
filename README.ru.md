# Блокаут

Опишите шот словами — получите грубый черновик: серые формы, траектории, движение
камеры. Дальше он идёт референсом в видеомодель, которая рисует поверх заданной
структуры.

Без Blender, без установки, в браузере и на телефоне.

## Запуск

```bash
npm run build      # собирает dist/blockout.html
open dist/blockout.html
```

`npm test` — проверки солвера. `npm run check` — то и другое.
Зависимостей нет, нужен только node.

## Как устроено

Языковая модель раскладывает описание на **отношения** («машина слева от человека,
если смотреть с его стороны»), а координаты, систему отсчёта, расталкивание тел и
дугу камеры считает `src/solver.js`. Причина такого разделения — в `CLAUDE.md`.

## Что уметь

- собрать сцену по описанию, поправить мышью, закрепить объект на нужной секунде
- переключиться между камерой шота и свободным обзором, снять камеру с текущего вида
- сохранить кадр (PNG) или весь шот (WebM) — это и есть референс для видеомодели
